# gRPC Inventory Backend

The backend server for the gRPC Inventory System, built with **.NET** using gRPC services for Inventory and Payment processing.

## Related Project
🖥️ **Frontend:** https://github.com/Hanna-adel/grpc-inventory-frontend

## Projects Structure
- **Inventory.Server** - gRPC server handling inventory operations
- **Payment.Server** - gRPC server handling payment operations
- **Lab1.API** - REST API that communicates with gRPC services

## Technologies
- .NET 10
- gRPC / Protobuf
- ASP.NET Core
